# EV-Navigator

**نسخه 13.3.1 | کد ساخت 134**

EV-Navigator یک پلتفرم متن‌باز و پیشرفته مسیریابی خودروهای برقی برای اندروید است که با هدف ترکیب مسیریابی هوشمند، پیش‌بینی فیزیک‌محور مصرف انرژی، تحلیل زیرساخت شارژ و برنامه‌ریزی سفر متناسب با مشخصات خودرو توسعه داده می‌شود.

## قابلیت‌های اصلی

- **مسیریابی هوشمند:** محاسبه مسیر، ارزیابی مسیرها و ارائه اطلاعات موردنیاز برای تصمیم‌گیری در حین رانندگی.
- **پیش‌بینی فیزیک‌محور انرژی:** تخمین مصرف انرژی متناسب با مشخصات خودرو، شرایط رانندگی و پارامترهای محیطی.
- **هوشمندی باتری:** تخمین وضعیت شارژ باتری (SOC) و پیش‌بینی میزان شارژ هنگام رسیدن به مقصد.
- **زیرساخت شارژ:** اطلاعات ایستگاه‌های شارژ، سازگاری کانکتورها، توان شارژ و برنامه‌ریزی سفر با درنظرگرفتن ایستگاه‌های شارژ.
- **پایگاه داده خودروها:** مشخصات ساختاریافته خودروهای برقی و امکان تعریف پروفایل خودرو.
- **یکپارچه‌سازی شرایط آب‌وهوا:** استفاده از شرایط محیطی در مدل‌های محاسبه مصرف انرژی.
- **معماری مسیریابی:** اجزای ماژولار برای مسیریابی، تحلیل پروفایل جاده، تطبیق موقعیت با نقشه و اجرای ناوبری.
- **یکپارچه‌سازی خودرویی:** توسعه قابلیت‌های مرتبط با Android Auto و تجربه‌های خودرویی.

## اصول مهندسی

- اولویت با داده‌های واقعی و قابل ردیابی به‌جای مقادیر ساختگی یا تأییدنشده است.
- اطلاعات ناموجود باید به‌صورت صریح و با وضعیت UNKNOWN نمایش داده شوند.
- عدم قطعیت مدل‌ها باید ثبت شود و فرضیات نباید به‌عنوان واقعیت تأییدشده نمایش داده شوند.
- از مقادیر پیش‌فرض پنهان که می‌توانند دقت پیش‌بینی انرژی را مختل کنند اجتناب می‌شود.
- معماری باید ماژولار، قابل آزمایش و قابل نگهداری باشد.
- قابلیت اطمینان، عملکرد و کیفیت تجربه کاربری از اولویت‌های پروژه هستند.

## معماری پروژه

پروژه از ماژول‌های مستقل و مرتبط تشکیل شده است:

- `app` — اپلیکیشن اندروید و نقاط ورود برنامه.
- `core` — زیرساخت اصلی و اجزای مشترک.
- `core/energy` — مدل‌سازی و پیش‌بینی مصرف انرژی.
- `core/roadprofile` — پردازش پروفایل جاده و اطلاعات ارتفاعی.
- `core/routing` — موتورهای مسیریابی و مدل‌های مسیر.
- `data` — منابع داده، مخازن و کاتالوگ‌ها.
- `domain` — منطق اصلی برنامه، مدل‌ها و موارد کاربرد.
- `feature` — قابلیت‌های برنامه و رابط کاربری.
- `design-system` — اجزای مشترک رابط کاربری و سیستم طراحی.
- `navigation` — اجزای ناوبری و اجرای مسیر.
